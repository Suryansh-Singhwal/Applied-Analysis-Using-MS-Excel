# PhonePe UPI Transaction Dashboard

An interactive Microsoft Excel dashboard for analyzing UPI transaction performance across geography, banks, payment apps, transaction types, merchants, demographics, and time.

## Key Insights

- Overall transaction success rate is 90.97%.
- PhonePe has the largest transaction share among the displayed UPI apps.
- Transaction activity varies significantly by hour and day.
- Transaction value differs across states and banking partners.
- P2M transactions contribute significantly to overall transaction value.
- 8,244 transactions are identified as suspected fraud.
